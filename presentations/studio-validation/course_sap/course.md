# SAP Order-to-Cash — Course

_4 modules from the source._

## Module 1: Sales Orders
- **Objective:** understand sales orders and apply it.
- **Summary:** A sales order is a customer request to deliver goods. Create it with VA01, change with VA02, display with VA03. The header is stored in table VBAK and items in VBAP.
- **You will be able to:** name the key steps/objects and complete the Module 1 exercise.

## Module 2: Delivery
- **Objective:** understand delivery and apply it.
- **Summary:** The outbound delivery is created with VL01N. Header table LIKP, items LIPS. Goods issue posts movement type 601 and reduces inventory.
- **You will be able to:** name the key steps/objects and complete the Module 2 exercise.

## Module 3: Billing
- **Objective:** understand billing and apply it.
- **Summary:** Billing is created with VF01. Header table VBRK, items VBRP. Billing creates an FI document in tables BKPF and BSEG.
- **You will be able to:** name the key steps/objects and complete the Module 3 exercise.

## Module 4: Returns
- **Objective:** understand returns and apply it.
- **Summary:** A return order uses VA01 with order type RE. Credit memo processing follows with VF01.
- **You will be able to:** name the key steps/objects and complete the Module 4 exercise.
