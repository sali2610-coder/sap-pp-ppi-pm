## conflicts

- `tx:MB04` — `data/tx-intel.ts#MB04` says "זמין ב-S/4HANA" and names an "Advanced Subcontracting Cockpit"; the Simplification List item S4TWL - AVAILABILITY OF TRANSACTIONS IN MM-IM (2025 FPS01 item 15.3.9, 2023 FPS03 item 27.6) lists MB04 among the MB codes replaced by MIGO / BAPI_GOODSMVT_CREATE (code exists, menu call raises an error), and no official record prints "Advanced Subcontracting Cockpit" (MM-IM documentation says "Subcontracting Cockpit"). The documented Fiori alternative, Post Subsequent Adjustment (F5476, loio 79824a704b7742ff8252c0c8575fbea3), is not in `data/fiori/apps.ts`. Same F0843 naming conflict as `tx:MIGO` (officially Post Goods Receipt for Purchasing Document; `apps.ts` calls it Post Goods Movement).
- `tx:MB05` — `data/tx-intel.ts#MB05` calls the code "זמין ב-S/4HANA" and describes it as "התאמת צריכה לפי תפוקה (Subsequent Adjustment by Output Quantity)"; the same Simplification List item lists MB05 twice as replaced, and no official title or snippet found on 2026-09-24 supports the "by output quantity" description (help.sap.com queries listed in the record's notes). The ECC role page (SAP Library NW 7.0 SPS12) documents subcontracting subsequent adjustment under MB04, not MB05. The function of MB05 stays "דורש אימות במערכת SAP".
- `tx:MB22` — `data/tx-intel.ts#MB22` (and `#MB21`) pair the code with "Manage Reservations (F1622)"; no official record names an app of that name or that id (query 'F1622' returns F1522 / F1602 / F1652 / F2600 / F2596 / F6122 only). The documented apps in 2025.001 are Manage Manual Reservations (F4839) and Manage Reservation Items (F5601), plus Job Scheduling - Manual Reservations (F7554); none is in `data/fiori/apps.ts`. MBVR and RKPF are not in the id universe.
- `tx:MB56` — no record in `data/tx-intel.ts`, `data/lifecycle.ts` or `data/transactions.ts` (the builder derives "לא קיים תיעוד מאומת במאגר"); only `data/tcode-directory.ts` and `data/process-guides.ts` describe it and tie it to CHVW, which no official record names. `audit/master-completion/simpl-tcode-index.json` attributes the MB56 mention to item 30.9 (S4TWL - ANSI/ISA S95 Interface) because the 2023 list prints '30.10S4TWL' … '30.40S4TWL' without a space; the sentence is in item 30.27 (S4TWL - Batch History, p. 799). - `tx:MBRL` — `data/tx-intel.ts#MBRL` says "זמינה" with fiori "Post Goods Movement (MIGO)"; the Simplification List item lists MBRL twice as replaced (2025 FPS01 15.3.9, 2023 FPS03 27.6). - `tx:ME21N` — `data/tx-intel.ts#ME21N` and `data/lifecycle.ts#ME21N` pair F0842A with "Create Purchase Order (Advanced)"; officially (Sourcing and Procurement 2025.001; Fiori Apps Library Apps('F0842A')/S32OP via `scripts/fal-app.mjs`) F0842A is Manage Purchase Orders (Version 2), predecessor F0842, and Create Purchase Order - Advanced carries the app id ME21N (SAP GUI).
