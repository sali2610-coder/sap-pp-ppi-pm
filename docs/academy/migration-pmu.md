# PR-8 · PM-User migration → Lesson block engine (pilot)

**Content-preserving migration** of the PM-User digital textbook to the canonical
Academy lesson engine. Generated by `scripts/migrate-academy-module.mts pmu` — never
hand-edited. Regenerate with the same command.

## Source → target coverage (100%, zero loss)
| metric | source (PMU_TEXTBOOK) | generated (pmu-generated.ts) |
|--------|----------------------|------------------------------|
| chapters | 10 | 10 (PMU_PATH) |
| lessons (subchapters) | 67 | 67 |
| sections (nodes incl children) | 271 | folded into the 67 lessons' blocks |
| words | 75,872 | 98,633 (≥ source — sub-headings/bullets/labels add, none removed) |
| unique SAP objects (T-Codes/tables/Fiori) | 551 | 551 |
| blocks | — | 1,120 |

Each subchapter → exactly one Lesson (`pmu-<id>`). Descendant nodes (source
"sections") are aggregated into that lesson's blocks, each child prefixed with its
title as a sub-heading — so no lesson is merged away and every word/object survives.

takeawaysHe→key-concepts + summary · scenarioHe+processExampleHe→cbc-example ·
flow→flow · tables→tables · tcodes→tcodes · fiori→fiori · configHe→spro ·

`relatedHe` cross-links pointed at legacy `/library/pmu/chapter-NN` routes that are
not generated (would 404) — their labels are preserved as text inside `notes`; no
`related` block with a dead href is emitted. No learning content lost.
