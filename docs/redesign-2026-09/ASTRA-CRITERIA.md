# Astra: קריטריונים שעודכנו

מטריצת Astra (`scripts/qa/astra-reverify.mjs`, 140 שורות) נכתבה לעיצוב הקודם. חלק מהבדיקות קיבעו ניסוח או מבנה שהוחלפו בכוונה בעיצוב החדש. לפי הבריף (§26), בדיקה כזאת מתעדכנת רק יחד עם קריטריון קבלה חדש וראיה. שום בדיקה לא נמחקה ושום סף לא הורחב כדי לעבור.

בכל שורה: הבדיקה, הקריטריון הישן, הקריטריון החדש, המקור להחלטה, והמדידה.
