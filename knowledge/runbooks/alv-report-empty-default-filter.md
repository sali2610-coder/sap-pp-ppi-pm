# Runbook · דוח ALV נפתח ריק — פריסת ברירת-מחדל עם סינון (Layout/Filter) · PP + Cross

<div dir="rtl">

**מתי:** דוח (בעיקר Z-report מבוסס ALV) נפתח **ריק/בלי שורות**, אבל כשמבצעים **עורך → מחק סינון** הנתונים מופיעים. חוזר בכל כניסה. לרוב **אצל כמה משתמשים**, לא רק אחד.
**מודולים:** Cross · PP (וכל מודול עם דוחות ALV).

## השורש
לדוח שמורה **פריסת ALV (Layout) המסומנת כברירת-מחדל/ראשונית**, ובתוכה **סינון (filter) פעיל** שמסתיר את כל השורות. **הנתונים כן נטענים** — הסינון מחביא אותם. "מחק סינון" בזמן ריצה מנקה **זמנית בלבד**; הוא לא נוגע בפריסה השמורה, ולכן הסינון חוזר בכניסה הבאה.

**מפתח לאבחון:** אם **עורך → מחק סינון** מציג נתונים → זו לא בעיית סלקציה/הרשאה אלא **סינון בפריסה**. אם קורה **לכמה משתמשים** → הפריסה **גלובלית** (default לכולם), לא אישית.

## תיקון קבוע (בסדר הזה)
### שלב 1 — שמור פריסה נקייה כברירת-מחדל
1. אחרי **עורך → מחק סינון** (נתונים מוצגים).
2. **הגדרות → פריסה → שמור** (Settings → Layout → Save).
3. סמן **"פריסה ראשונית"** (ברירת מחדל) כדי שתיטען אוטומטית.
4. אם הבעיה אצל כמה משתמשים — **בטל את הסימון "ספציפי למשתמש"** כדי לשמור **גלובלית** (לכולם). דורש **הרשאת S_ALV_LAYO (תחזוקה)**; אחרת Basis/מורשה.

### שלב 2 — תקן/הסר את הפריסה ה"רעה" הקיימת
1. **הגדרות → פריסה → ניהול** (Layout → Management).
2. מצא את הפריסה המסומנת כברירת-מחדל/ראשונית (עם הסינון).
3. או **פתח והסר ממנה את הסינון** ושמור, או **בטל לה את דגל ברירת-המחדל** — כך הנקייה משתלטת.

⚠️ חובה לטפל **בשתיהן**: נקייה כ-default + הישנה בלי סינון/בלי דגל default. אחרת הישנה עלולה עדיין להיטען.

## למה תיקון אישי לא מספיק
פריסה גלובלית פגומה → תיקון אישי פותר רק למשתמש אחד; שאר הקולגות ימשיכו לקבל ריק. **תקן את ה-default הגלובלי.**

## אבחנה — פריסה (ALV) מול וריאנט (מסך בחירה)
- **מחק סינון מציג נתונים** → סינון ב-**פריסת ALV** (הרנבוק הזה).
- **הדוח לא בכלל בוחר נתונים** (גם בלי סינון ריק) → ייתכן **וריאנט מסך בחירה** שגוי — טפל דרך וריאנט הבחירה (SE38/וריאנט), לא פריסה.

## מוצא (No Dead End)
מגיע ל: **שורש** (פריסת default עם סינון) · **תיקון** (שמירת פריסה נקייה גלובלית + הסרת הישנה) · **הבהרה** (משתמש אחד או כמה? → אישית מול גלובלית) · **הסלמה** (הרשאת S_ALV_LAYO / Basis לפריסה גלובלית). קייס אמיתי: `../cases/2026-08-alv-report-empty-filter-zpp-pord-cons.md`.
