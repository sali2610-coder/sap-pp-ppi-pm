# Runbook · מק"ט לא נקלט בשדה חומר ב-S/4 (עבד ב-ECC) — Exit בהמרת MATN1 · Cross

<div dir="rtl">

**מתי:** אחרי מעבר ECC→S/4, הקלדת מק"ט בשדה חומר (רכיבים, הזמנות, רשימות משימות) מקפיצה הודעה לא צפויה (למשל `LF014` "לא נמצא זיהוי חומר עבור EAN") והשורה נדחית — **לכל מק"ט**, בעוד ש-ECC עובד.
**קייס אמיתי:** `../cases/2026-10-ia06-lf014-sd-user-exit-matn1.md`.

## העיקרון
שדה מק"ט עובר **שגרת המרה `MATN1`**. כל קוד לקוח שיושב בה — Customer Exit **`EXIT_SAPLOMCV_001`** (שיפור **`MGA00003`**) או **`BADI_MATN1`** — **רץ על כל הקלדת מק"ט בכל המערכת**, לא רק בטרנזקציה שבשבילה נכתב. "קורה לכל מק"ט" = לא בעיית נתוני אב.

## אבחון, לפי סדר (קריאה בלבד)
1. **מספר ההודעה:** לחיצה כפולה על ההודעה → Performance Assistant → מידע טכני (מחלקה, מספר, תוכנית, include, שורה). **צעד ראשון, תמיד.**
2. **שלילת נתונים:** `OMSL` (השוואת שתי מערכות) · `MARC` למק"ט+אתר.
3. **מי קורא:** `SE37` → הפונקציה שמעלה את ההודעה → Where-Used (ממסך הפתיחה, `Ctrl+Shift+F3`). חפש include מסוג `ZX...`.
4. **לאיזה Exit שייך ה-include:** `SE38` → include → Where-Used → `EXIT_SAPL...`.
5. **האם הפרויקט פעיל:** `SE16N` → `MODACT` (`MEMBER` = שם השיפור) → `MODATTR` (`NAME` = פרויקט) → `STATUS = A`.
6. **השוואת קוד:** `SE38` → include → העתקה משתי המערכות → diff.
7. **הוכחה:** דיבאגר (`/h`) → Breakpoint at → Function → הפונקציה החשודה → F8 → **ABAP and Screen Stack** + ערכי משתנים. לחזור על זה במערכת השנייה ולהשוות תוצאה.
8. **מי מציג בפועל את ההודעה:** Breakpoints → Breakpoint at → **Statement** → לשונית ABAP Cmnds → `MESSAGE`. F8 שוב ושוב; עצירות על `MESSAGE ... RAISING` הן "שקטות". העצירה הראשונה על `MESSAGE` **בלי** `RAISING` (למשל `MESSAGE ID sy-msgid ...`) היא המציגה. לצלם את ה-`IF` שמעליה — לרוב בודק `sy-msgty`.
9. **השוואת Notes:** הערות `StartNote`/`EndNote`/`"N<מספר>` בקוד שנמצא → `SNOTE` בשתי המערכות / חיפוש המספר ב-include המקביל ב-ECC.

## טיפול
- התיקון בקוד ה-Z: להגביל את הלוגיקה לטרנזקציה/הקשר שלשמם נכתבה, **לפני** כל קריאה שמשנה את הקלט או עלולה להעלות הודעה.
- בעלות: הצוות שכתב את ה-Exit (לא בהכרח המודול שנפגע). פיתוח בסביבת פיתוח + בקשת שינוי + רגרסיה בשני המודולים.
- **לא Note/OSS** — Customer Exit הוא קוד לקוח. SAP מתעדת את כללי שגרות ההמרה (ABAP Keyword Documentation, "Conversion Routines"), לא את התנהגות קוד הלקוח בתוכן.

## מלכודות
- Where-Used מתוך הקוד מחזיר "No where-used list possible" — להריץ ממסך הפתיחה.
- ניתוחי AI חיצוניים נוטים להמציא שמות BAdI ו-KBA. לאמת כל שם ב-`SE18`/`SE84` וכל KBA בכותרת שלו.
